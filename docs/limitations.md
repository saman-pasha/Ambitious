# Limitations, as of Phase 12 (in progress)

What each module does not do, so that a reader knows what an answer can rest
on. Each module's file says the same at its top.

| module | not done |
|---|---|
| HTML (`src/html/`) | the guess at an encoding nothing declares weighs letters one by one, where Chromium's detector weighs pairs of bytes: of 145 sample pages (21 encodings, some 35 languages) it names Chromium's encoding for all but 8, each one Chromium's guess misreads (Czech in ISO-8859-2, which Chromium names windows-1250; "déjà" alone, windows-1257; two bytes alone, Shift_JIS; a file of UTF-8 with a stray byte, ISO-8859-4 or 10; undeclared EUC-JP in a file, GBK); it guesses none of windows-1258, x-mac-cyrillic or the ISO-8859 encodings but 2, 5, 6 and 7 |
| CSS (`src/css/`) | `@container` and `@counter-style`, which are skipped; of the `-webkit-` names, those Chromium keeps as aliases are read and `-webkit-text-fill-color`, `-webkit-line-clamp` on a vertical `-webkit-box` or `-webkit-inline-box` (computed `flow-root` or `inline-block`, as Chromium computes them; its ellipsis in the clamping box's style, where Chromium takes the line's block's), and the old `-webkit-box` itself as a block, or as a row of its children when horizontal (not the old flexbox's own sizing), but not its other prefixed properties (`-webkit-text-stroke`, `-webkit-mask`); of animations (each evaluated at the page's rest time, 10 s after it loaded, as Chromium draws it then): transform lists whose functions differ are not interpolated through their matrices (the first value holds until halfway), and scroll-driven animations (`animation-timeline`) and `animation-composition` are not read; a transition does nothing at rest; `:visited`, which holds of nothing (no history is read); the writing-mode properties; of SVG's properties: `marker`, `mask`, `paint-order`, `vector-effect`, `dominant-baseline`, the geometry ones (`x`, `r`, `cx`, `d`, ...), and of `clip-path`: a `url()` on an HTML box (computed, not drawn, where Chromium clips the box to the SVG `clipPath`), and a basic shape on an inline element (not an atomic inline: its fragments and text are not clipped) or on an element inside an `<svg>` (a block's, an atomic inline's and an `<svg>`'s basic shapes, geometry boxes, `xywh()` and `rect()` clip them as Chromium does) |
| Layout (`src/layout/`) | writing modes; of bidirectional text (UAX #9 by characters, its embeddings, isolates and brackets): under `plaintext` a `<br>` starting a paragraph of its own, an inline box's edges on its later lines in a right-to-left paragraph, and `text-indent` there; hyphenation in en-US alone; of grid: subgrid, masonry, baseline alignment, and of a grid container's own min- and max-content widths, its items' line placements, spans and flexible tracks' shares (it reckons its items in turn along the rows, a fixed column its size and any other its widest item's); a flex container's last baseline (its first is used); a sticky inline element (it has no box; a sticky box is placed as at rest, unscrolled); form controls' look in the light scheme alone (Chromium's theme draws its dark colours under a dark scheme), at rest (a control disabled, focused or hovered is drawn as an enabled one at rest), and of a date field and a file chooser their box alone (their text and icon sized as a whole; a date field's picker and a file chooser's button are not drawn); a text field's character width follows Chromium's, measured on 212 fields of six faces at 28 sizes, three of which it misses by a px; a marker placed inside a list item whose first line is a nested block's (`<li><p>`) is placed outside, where Chromium sets it in that block's first line; a fieldset's legend wider than its fieldset's content (Chromium's legend may overflow the border; a fieldset's own min-content width leaves its legend out); a broken image in a quirks-mode page is laid out as in a standards-mode one (the document's mode is not kept) |
| Paint (`src/paint/`) | images in AVIF, and lossless JPEG (PNG, GIF, JPEG and WebP are decoded, an animation drawn at the frame it shows at rest; an arithmetic-coded or 12-bit JPEG draws nothing, as in Chromium); an image at a fractional x is placed at whole pixels, where Chromium resamples it; `object-fit` and `object-position` place a raster image, not an SVG image (drawn to fill its box); the planes of a 3D space (`transform-style: preserve-3d`) that cut through each other, each drawn whole by its middle's depth where Chromium splits them; a filter that names an SVG filter by `url()` (the whole filter is then ignored); `background-clip: text` on an inline element (its decorations are drawn, sliced at its line breaks, but not through its glyphs; on a block they are), and `box-decoration-break: clone`, drawn as slice; text: what the built-in faces (subsets of Liberation and DejaVu) have not is drawn from the machine's fonts Chromium falls back to, read from their files in fontconfig's order (Inter, WenQuanYi Zen Hei, Loma, FreeSans, FreeSerif, Unifont, DejaVu's and Liberation's own files, ...), but the fallback is chosen code point by code point where Blink chooses one font for a run of them; a fallback font's kerning (its GPOS pairs, FreeSerif's Ethiopic) is not read, nor a text emoji made emoji by U+FE0F; colour emoji (Noto Color Emoji's bitmaps) are measured but not drawn; `system-ui` is Liberation Sans, where Chromium takes the machine's fonts (Inter, the desktop's face); a mark HarfBuzz draws over a letter the face has no glyph for is drawn where the face's GPOS puts it only for the letters the built-in faces carry; a bold style's glyph that a regular face draws in its fallback is not emboldened as Chromium emboldens it (Skia's fake bold: the advance is kept, the outline thickened), and the generic `serif` family's bold and italic fall back as the default family's do (Chromium tries DejaVu Serif for it before the other fonts); a CFF charstring's accented character (seac, endchar's four operands) is not composed; no ligatures or shaping beyond kerning (GSUB, GPOS's marks, Arabic joining), no kerning from GPOS (a web font's pairs are read from its kern table alone), and no kerning across an inline element's edge; a WOFF2 collection is not read, and an `@font-face` source whose bytes begin as a font's but are none the painter reads is not passed over for the next (one that fails to load is); of SVG (`src/paint/svg.c`, inline and as an image): filters, masks, markers, patterns, `<image>` and `foreignObject` inside SVG, SMIL animation, `textPath`, a text's stroke, `rotate`, `textLength` and baseline properties, a rotated or skewed text run drawn upright, web fonts in SVG text (the built-in faces alone), `paint-order`, `vector-effect`, a reference into another document (`url(other.svg#id)`), `switch`'s conditions (its first child is drawn), and the geometry properties set by CSS (`r`, `cx`, `d`, a rect's `width`: read as attributes alone); curves are drawn as cubics (an arc's within 0.03% of its radius) where Skia draws conics |
| Network (`src/net/`) | HTTP/2 and HTTP/3 (HTTP/1.1 alone, over TLS 1.2 or 1.3 for https); a URL's query percent-encoded from UTF-8 always, never in a page's legacy encoding (the URL standard's encoding argument); of `<picture>`: a `<source>` of AVIF or BMP is passed over where Chromium takes it (the painter decodes neither), and a source's width and height are not its img's; images are chosen (srcset, sizes, a source's media) for an 800x600 viewport at 1x in the light scheme, whatever the profile sets for the cascade; iframes |
| Accessibility (`src/a11y/`) | Chromium's guess that a table is for layout (a table of one cell, say, which it exposes as a layout table): every `table` is a table here; a name from content walks the document's children, not the elements aria-owns moved under the node; a `counter()` in generated content adds nothing to a name, and its quotes are the first level's; a field's value too long or too short is never invalid, as no one has typed; a URL field is judged by the network module's parser, which refuses a space in a host that Chromium takes; Chromium names `math` from its content and drops an `option` outside a listbox, where both are kept as WAI-ARIA has them |
| Profile (`prolog/amb/profile.pl`) | a background tab keeps its clicks alone (made current again, its page is loaded again and they are replayed) |
| JavaScript (`src/js/`) | of `Intl` (ECMA-402, over CLDR's data for 29 languages, matching node's output): collation tailorings (Swedish, Danish, Finnish, Czech, Turkish, Hungarian, Romanian, Vietnamese, German phonebook, French Canadian accents compare by the root order), calendars but the Gregorian (Thai and Persian locales format Gregorian dates), time zones by IANA name (UTC, fixed offsets and the `Etc/GMT` zones are known; a name throws a RangeError), CJK and Thai words segmented by UAX #29's rules alone (ICU's dictionaries are not carried), and locales outside its 29 languages (taken as `en-US`); the collector (`src/js/gc.c`) runs only between tasks (a page's once its heap has doubled since the last, 32 MB at least), so the garbage of one script or timer lives until it ends; and what the page's host holds by number lives while the host may use it: every node's wrapper until another node takes its number, and a MutationObserver, an XMLHttpRequest, a custom element definition's class and callbacks, a Response's Headers, and a Headers or FormData object with entries, for the page's life; an array element's attributes (defineProperty's writable or configurable on an index) are not kept; normalization and `\p{}` read Unicode 15.0 (V8 17.0); `Function.prototype.toString` gives `function () { [code] }`, not the source; calling a value that is no function says `object is not a function`, where V8 names the expression (`f.reset is not a function`) |
| Scripts (`src/script/`) | shadow trees are not rendered (the cascade and layout walk the document's tree alone); the parser's insertions are not seen by observers (a page is parsed whole before its scripts run); a checkbox's checked state is its `checked` attribute, so a click on one is an attribute's change; `beforeunload` cannot cancel; `matchMedia`'s `change` never fires (the viewport is fixed) and neither does `storage` (one document a run); customized built-in and form-associated custom elements, `slotchange`, and `composedPath` hiding a closed tree's nodes; a form sent in a legacy multi-byte encoding writes a character it lacks as `&#N;` alone; a click's coordinates are found when first read, so they move if a listener moved the element first; a module script a script inserts is not run (the parser's are), an external import map is passed over without Chromium's console line, and over `file:` the refused modules' console lines come in the order their graphs are walked, where Chromium's come as its network answers |
| Reasoning | `advise` is not incremental (250 to 400 ms on a page of 16,000 nodes, its floor once a kept reasoner takes deltas); a change to a page's structure moves most facts, since the cascade, layout and accessibility renumber their records each run; the sandbox's syscall filter is made for x86-64 alone |
| Toolchain | the findings in `toolchain/REPORT.md`, among them no deep indexing in cocolog (worked around), a 16 MiB file read (worked around), and `struct addrinfo` not lowered from `<netdb.h>` (declared locally) |

# Limitations, as of Phase 12 (in progress)

What each module does not do, so that a reader knows what an answer can rest
on. Each module's file says the same at its top.

| module | not done |
|---|---|
| HTML (`src/html/`) | the guess at an encoding nothing declares weighs letters one by one, where Chromium's detector weighs pairs of bytes: of 145 sample pages (21 encodings, some 35 languages) it names Chromium's encoding for all but 8, each one Chromium's guess misreads (Czech in ISO-8859-2, which Chromium names windows-1250; "déjà" alone, windows-1257; two bytes alone, Shift_JIS; a file of UTF-8 with a stray byte, ISO-8859-4 or 10; undeclared EUC-JP in a file, GBK); it guesses none of windows-1258, x-mac-cyrillic or the ISO-8859 encodings but 2, 5, 6 and 7 |
| CSS (`src/css/`) | `@container` and `@counter-style`, which are skipped; of animations (each evaluated at the page's rest time, 10 s after it loaded, as Chromium draws it then): transform lists whose functions differ are not interpolated through their matrices (the first value holds until halfway), and scroll-driven animations (`animation-timeline`) and `animation-composition` are not read; a transition does nothing at rest; `:visited`, which holds of nothing (no history is read); the writing-mode properties |
| Layout (`src/layout/`) | writing modes; bidirectional text by words (no `unicode-bidi` embeddings or isolates, no bracket mirroring); hyphenation in en-US alone; grid's named lines and areas, column and dense auto-flow, and spanning items' share of the track sizes; flex's baseline alignment (as start); sticky positioning's offsets; an inline element as a containing block; form controls' own metrics and look (a button's border is drawn grey and computed so, where Chromium computes ButtonBorder and draws its own); a fieldset's legend set inside its border, where Chromium sets it on the top edge; a broken image's fallback as Chromium lays it out (unsized, a 16px box for its icon; with alt text in a standards-mode page, the icon and the text inline at the text's size): its box keeps the image's size and its alt text is not drawn |
| Paint (`src/paint/`) | inline `<svg>` (its box is laid out, its content not drawn); images in AVIF or SVG, and lossless JPEG (PNG, GIF, JPEG and WebP are decoded, an animation drawn at the frame it shows at rest; an arithmetic-coded or 12-bit JPEG draws nothing, as in Chromium); an image at a fractional x is placed at whole pixels, where Chromium resamples it; an `<img>` with no `src` draws nothing, where Chromium draws its fallback's silver border; the planes of a 3D space (`transform-style: preserve-3d`) that cut through each other, each drawn whole by its middle's depth where Chromium splits them; a filter that names an SVG filter by `url()` (the whole filter is then ignored); `background-clip: text` (its layer is not drawn); text: the built-in faces (subsets of Liberation and DejaVu, as Chromium draws the generic families on Linux) hold Latin-1, Greek's small letters, Hebrew and some symbols, a code point beyond them drawn as U+FFFD, and `system-ui` is Liberation Sans, where Chromium takes the machine's fonts (Inter for a star or a check, the desktop's face); no ligatures or shaping beyond kerning (GSUB, GPOS's marks, Arabic joining), and no kerning across an inline element's edge; web fonts in WOFF2 or with CFF outlines are not read |
| Network (`src/net/`) | HTTP/2 and HTTP/3 (HTTP/1.1 alone, over TLS 1.2 or 1.3 for https); a URL's query percent-encoded from UTF-8 always, never in a page's legacy encoding (the URL standard's encoding argument); `<picture>`'s `<source>`s; iframes |
| Accessibility (`src/a11y/`) | visibility (the cascade does not compute it); a closed `details`' content and a `dialog` without open; CSS generated content; constraint validation (invalid comes from aria-invalid alone); presentational children and inherited presentation; aria-owns reordering the tree |
| Profile (`prolog/amb/profile.pl`) | a background tab keeps its clicks alone (made current again, its page is loaded again and they are replayed) |
| JavaScript (`src/js/`) | of `Intl` (ECMA-402, over CLDR's data for 29 languages, matching node's output): collation tailorings (Swedish, Danish, Finnish, Czech, Turkish, Hungarian, Romanian, Vietnamese, German phonebook, French Canadian accents compare by the root order), calendars but the Gregorian (Thai and Persian locales format Gregorian dates), time zones by IANA name (UTC, fixed offsets and the `Etc/GMT` zones are known; a name throws a RangeError), CJK and Thai words segmented by UAX #29's rules alone (ICU's dictionaries are not carried), and locales outside its 29 languages (taken as `en-US`); `<script type=module>` in pages (the engine has modules: `ambitious js` runs a `.mjs` file, `import()` loads files); the collector (`src/js/gc.c`) runs for `ambitious js` alone: a page's objects live as long as the page, under a cap, until the script module's own state is among its roots; an array element's attributes (defineProperty's writable or configurable on an index) are not kept; normalization and `\p{}` read Unicode 15.0 (V8 17.0) |
| Scripts (`src/script/`) | node lists are arrays, read once, not live; `getComputedStyle` reads the inline style and `getBoundingClientRect` is empty (the scripts run before the cascade and layout); `fetch`, XHR, inserted scripts and `document.write`; keyboard, focus and pointer events beyond a click; forms' submission; `MutationObserver`, shadow DOM, custom elements; the window's properties beyond its timers, `location` and `navigator` |
| Reasoning | `advise` is not incremental (250 to 400 ms on a page of 16,000 nodes, its floor once a kept reasoner takes deltas); a change to a page's structure moves most facts, since the cascade, layout and accessibility renumber their records each run; the sandbox's syscall filter is made for x86-64 alone |
| Toolchain | the findings in `toolchain/REPORT.md`, among them no deep indexing in cocolog (worked around), a 16 MiB file read (worked around), and `struct addrinfo` not lowered from `<netdb.h>` (declared locally) |
